Explications
À quoi sert ce tableau ? Il regroupe des indicateurs de suivi pour le territoire couvert (ici Paris) : nombre de sources de données connectées, puis trois graphiques sur l’historique en base. Ces chiffres ne sont pas des objectifs politiques ni des normes légales ; ils reflètent ce que l’application a pu collecter et agréger à la dernière synchronisation.
Stations météo

Nombre de points de mesure météo suivis dans la base (réseau couvert par l’appli), pas la température du jour.

Réseaux vélos

Nombre de réseaux de vélos en libre-service intégrés (opérateurs / zones), pas le nombre total de vélos physiques.

Capteurs pollution

Nombre de capteurs qualité de l’air suivis ; plus le réseau est dense, plus les cartes et moyennes sont représentatives localement.

Total observations

Somme de toutes les observations en base : météo + pollution + snapshots vélos. Indicateur de la richesse du jeu de données collecté.

La date affichée est l'horodatage le plus récent parmi les trois sources (synchro la plus fraîche dans le système).

Météo — Température moyenne mensuelle

Moyenne des températures enregistrées en base, par mois (historique disponible). Utile pour comparer les saisons, pas pour la météo instantanée.

Axe horizontal : mois (année-mois). Axe vertical : degrés Celsius (°C). Chaque barre = moyenne sur toutes les observations de ce mois dans la base.

Mobilité — Vélos disponibles par heure

Moyenne du nombre de vélos signalés comme disponibles, regroupée par tranche horaire (0h–23h), sur l’historique en base. Indique les habitudes d’usage (pics creux), pas la capacité totale du parc.

Axe horizontal : heure de la journée. Axe vertical : nombre moyen de vélos disponibles (toutes stations confondues selon les données chargées). Les heures sans mesure apparaissent comme un trou dans la courbe.

Pollution — Variation journalière par polluant

Concentration moyenne dans l’air par heure de la journée (toutes mesures agrégées), pour chaque polluant (ex. PM2.5, PM10, O₃). Unité : µg/m³ (microgrammes par mètre cube). Une courbe absente = pas de mesure exploitable pour ce polluant dans la période.

Les valeurs physiquement impossibles (ex. concentrations < 0, souvent erreur capteur) sont ignorées sur le graphique. Ce graphique aide à repérer des profils typiques (trafic, journée) ; il ne remplace pas un indice officiel ou réglementaire.
